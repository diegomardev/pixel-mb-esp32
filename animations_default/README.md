# Animaciones personales

Coloca aquí tus archivos JSON y ejecuta:

```sh
python3 tools/install_default_animations.py --host http://IP_DEL_ESP --upload
```

Los JSON de esta carpeta se excluyen de Git. El repositorio incluye ejemplos propios y cuatro efectos con atribución en `data/animations` y `examples`; no redistribuye el catálogo descargado de AWTRIX Hub ni logos aportados para uso personal. Puedes previsualizar y descargar animaciones desde https://diegomardev.com/apps/pixel-mb; comprueba los permisos del autor de cada archivo antes de redistribuirlo.
